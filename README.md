## HTML

HTML används för att skapa strukturen på en webbsida.

### Exempel

```html
<h1>Det här är en rubrik</h1>
<p>Det här är ett stycke text.</p>
```

- `h1` används för rubriker.
- `p` används för textstycken.
- `ul` används för listor.
- `a` används för länkar.
